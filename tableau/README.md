# Tableau Public dashboard

`istanbul_transit_tableau.xlsx` holds Tableau-ready tables exported from the DuckDB warehouse
(`python tableau/export_tableau.py`, regenerated by the Analysis workflow). Open it in Tableau Public
(**Connect → Microsoft Excel**); each sheet is one data source, described in the `README` sheet.

## Dashboard 1 — Network overview
| Chart | Sheet | Build |
|---|---|---|
| KPI tiles: 2023 passengers, daily average, YoY | `monthly_kpis` | Filter `Complete month` = True, year 2023; SUM(`Passengers`) |
| Recovery index by mode | `monthly_kpis` | Line: `Month` (continuous month) × `Recovery index (%)`, colour `Mode`; reference line at 100 |
| Mode share by year | `monthly_kpis` | 100% stacked bar: YEAR(`Month`) × SUM(`Passengers`), colour `Mode`, quick table calc *Percent of total* |
| Daily demand calendar | `daily` | Calendar heatmap: WEEKDAY(`Date`) × WEEK(`Date`), colour SUM(`Passengers`), filter by year |

## Dashboard 2 — Capacity
| Chart | Sheet | Build |
|---|---|---|
| Top 15 lines | `line_monthly` | Bar: `Line` × SUM(`Passengers`), filter YEAR(`Month`) = 2023, Top 15 |
| Peak-hour load | `line_peak_2023` | Bar: `Line` × `Peak hour passengers (avg weekday)`, label `Peak hour` |
| Line × hour heatmap | `line_hour_2023` | Highlight table: `Line` (rows) × `Hour` (columns), colour `Passengers (2023 total)`, filter `Day kind` |
| Hour-of-day profile | `hourly_profile` | Line: `Hour` × `Avg passengers`, colour `Day kind`, filter `Mode`, `Year` |

## Dashboard 3 — Pricing and special days
| Chart | Sheet | Build |
|---|---|---|
| Fare mix over time | `fare_mix` | Area: `Month` × SUM(`Share (%)`), colour `Card group` (annotate October 2023) |
| Payment types | `fare_mix` | Bar: `Payment type` × SUM(`Passengers`), filter year |
| Special-day effect per line | `special_days` | Diverging bar: `Line` × `Change vs ordinary weekday (%)`, filter `Day type`, sort ascending |
| Day-type distribution | `daily` | Box plot: `Day type` × `Passengers`, filter `Mode` |
| Rail and ferry districts | `districts_2023` | Bar: `District` × `Share (%)`, colour `Rail share (%)` |

Filters to add on every dashboard: `Mode`, year. Title each dashboard with the business question it answers
("Where is the network stretched?", "Who pays what?", "How should service change on special days?").
